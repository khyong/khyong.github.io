## Lab projects

The lab track introduced practical skills complementary to the lectures, with six lab assignments over the semester.

- **Lab 0.** Environment setup (Google Colab, GIST GPU servers, Kaggle and GitHub submission)
- **Lab 1.** Representation of symbolic data
- **Lab 2.** NLP data preparation (midterm project)
- **Lab 3.** Problem formulation
- **Lab 4.** Encoder-decoder implementation
- **Lab 5.** Transformer implementation

All lecture materials are kept confidential to the course.
