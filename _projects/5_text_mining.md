During my M.S. at UST-KISTI, I built a clustering module for **semi-real-time issue analysis** of Korean news articles, combining hierarchical and incremental clustering with word embeddings {% cite kim2019hierarchical kim2020hierarchical %}. Related work includes a word semantic similarity model built from the Korean Open Dictionary {% cite kim2018word %}, a web crawler and network analysis pipeline for flood prediction {% cite seo2019flooding %}, and applied prediction models for sports rankings {% cite jin2019kbl %} and traffic accident points {% cite kim2019feature %}.
